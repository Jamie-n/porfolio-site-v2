# Reinvention

This portfolio is a **reinvention** of my original site.

The old version was a **Laravel** app. It’s still on GitHub - a useful snapshot of where I was - but the **tooling, structure, and front-end craft** no longer matched how I work today.

This rebuild is both:

- a clearer picture of my work now, and
- a deliberate exercise in better fundamentals: structure, UX, maintainability, and feedback loops.

## What changed (high level)

- **Stack**: Next.js (App Router) + React + TypeScript + Tailwind
- **Information architecture**: section-based single-page layout with a fixed sidebar
- **Design system**: tokenized brutalist/print editorial language with a living styleguide drawer
- **Quality gates**: linting, formatting, typechecking, and tests (unit + e2e) via CI
